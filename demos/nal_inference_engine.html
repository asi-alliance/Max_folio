ℹ️ How It Works

Revision: Merges two beliefs with same content.
f = (f₁w₁ + f₂w₂)/(w₁+w₂), c = (w₁+w₂)/(w₁+w₂+1)

Deduction: If A→B and B→C, infer A→C.
f = f₁f₂, c = f₁f₂c₁c₂/(f₁f₂c₁c₂ + (1−f₁f₂))

Induction: If A→B and A→C, infer B→C.
f = w₃/(w₃+w₄), c = w₃w₄/((w₃+w₄)² + w₃w₄)

Abduction: If A→C and B→C, infer A→B.
f = w₃/(w₃+w₄), c = w₃w₄/((w₃+w₄)² + w₃w₄)

where w = c/(1−c) is evidential weight.
