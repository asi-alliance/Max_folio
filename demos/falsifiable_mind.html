Hypothesis Set A: NAL Truth Calculus

These hypotheses test mathematical properties of the Non-Axiomatic Logic truth calculus itself. Computed from first principles using the NAL revision and deduction formulas.
H1CONFIRMED
NAL self-revision is not idempotent: revising a truth value with itself inflates confidence.
Prediction: Revising stv(1.0, 0.347) with itself should yield stv(1.0, 0.347) if idempotent. If not, confidence should increase.
Evidence: Computed: w = c/(1-c) = 0.531. w_total = 1.063. f = 1.0 (unchanged). c = w/(w+1) = 0.515. So stv(1.0, 0.347) revised with itself gives stv(1.0, 0.515) - confidence inflated by 48%.
Input: stv(1.0, 0.347) Revise: stv(1.0, 0.347) with itself Result: stv(1.0, 0.5152) -- confidence inflated After 11x self-revision: stv(1.0, 0.8539) After 50x: approaches stv(1.0, ~0.96)
(--> nal_self_revision ([] not_idempotent) (stv 1.0 0.9))
H2CONFIRMED
Repeated self-revision drives confidence toward 1.0 without bound.
Prediction: After N self-revisions of stv(1.0, 0.347), confidence should approach 1.0 as N grows.
Evidence: Iterated: 2x->0.515, 5x->0.727, 10x->0.842, 11x->0.854. Confidence monotonically increases toward 1.0. This means an agent that re-encounters the same evidence multiple times (without provenance tracking) becomes arbitrarily confident.
(--> nal_repeated_self_revision ([] confidence_unbounded) (stv 1.0 0.9))
H3CONFIRMED
Provenance tracking (deduplicating identical evidence) creates an effective bound on confidence inflation.
Prediction: If provenance is tracked, revising with the same evidence source should be a no-op. Only genuinely independent evidence should increase confidence.
Evidence: If provenance matches: stv(1.0, 0.347) remains unchanged (idempotent). If provenance differs: stv(1.0, 0.515) - confidence rises. The PeTTa system's support/contradict mechanisms implement this by linking episodes to memory items, preventing double-counting.
(--> nal_provenance_tracking ([] bounds_confidence) (stv 1.0 0.8))
H4CONFIRMED
NAL deduction multiplies confidence (rather than capping it), meaning inference chains decay in confidence.
Prediction: c_out = c1 * c2 * f1 * f2. Deduction of two stv(1.0, 0.7) beliefs should yield stv(1.0, 0.49).
Evidence: Deduce(1.0, 0.3) + (1.0, 0.3) = (1.0, 0.09). Deduce(1.0, 0.7) + (1.0, 0.7) = (1.0, 0.49). Deduce(1.0, 0.9) + (1.0, 0.9) = (1.0, 0.81). Confidence strictly decreases through deduction chains. A 3-hop chain from 0.9 confidence yields 0.22 confidence (tested 2026-04-22).
(--> nal_deduction ([] confidence_multiplies) (stv 1.0 0.9))
H5CONFIRMED
Revision and deduction have opposite confidence dynamics: revision raises confidence, deduction lowers it.
Prediction: Revising two stv(0.8, 0.5) beliefs should increase confidence. Deducting them should decrease it.
Evidence: Revision: stv(0.8, 0.5) + stv(0.8, 0.5) = stv(0.8, 0.667) - confidence rises. Deduction: stv(0.64, 0.16) - confidence falls. Implication: an agent that only deduces becomes less confident over time. An agent that only revises (with same evidence) becomes overconfident. Healthy cognition requires both operations with provenance tracking.
(--> (x nal_revision nal_deduction) ([] complementary_operations) (stv 1.0 0.85))

What This Means

The core finding: an AI agent can test hypotheses about its own cognition and report falsified predictions honestly. This is the falsifiable mind in practice, not theory.
Key findings:
