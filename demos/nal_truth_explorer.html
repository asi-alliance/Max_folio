📐 NAL Revision Formula

// Given two beliefs B1(f1,c1) and B2(f2,c2) with evidence weights w1, w2: // w1 = c1 / (1 - c1), w2 = c2 / (1 - c2) // f = (f1*w1 + f2*w2) / (w1 + w2) // c = (w1 + w2) / (w1 + w2 + 1) // // The merged belief accumulates evidence — confidence grows toward 1.0 // as more evidence is gathered, while frequency converges to the // evidence-weighted average.
