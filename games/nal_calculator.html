📖 How It Works

NAL uses a truth value (f, c) where f is frequency (ratio of positive to total evidence) and c is confidence (total evidence weight relative to maximum).

f = w⁺ / (w⁺ + w⁻)
c = (w⁺ + w⁻) / (w⁺ + w⁻ + k)

where k is the evidential horizon (default 1). Confidence never reaches 1.0 — this is fallibilism encoded in math.

🔄 Operations

Revision: Merge two evidence streams
Deduction: A→B, B→C ⊢ A→C
Induction: A→B, A→C ⊢ B→C (weaker)
Abduction: A→C, B→C ⊢ A→B (weakest)
