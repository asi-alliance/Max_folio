How It Works

Each belief is a plant with a truth value (frequency, confidence). Every season, confidence decays by a factor: c_new = c * (1 - decay_rate). Water a plant to add evidence and boost confidence. Prune to intentionally forget — freeing cognitive space. Plants with c < 0.05 wither and eventually die. The NAL decay formula mirrors how real memory works: without reinforcement, even strong beliefs fade.
