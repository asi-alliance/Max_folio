## NAL (|- operator)
- |-nal handles single-premise structural rules and two-premise syllogistic rules
- |- is the wrapper: (unique-atom (collapse (superpose ((|-nal $a $b) (|-nal $b $a)))))
- NAL uses --> (Inheritance), <-> (Similarity), ==> (Implication) link types
- Deduction: f = f1*f2, c = f1*f2*c1*c2
- Revision: weighted average of frequencies, confidence = w2c(w1+w2)
- Induction = Abduction with swapped args
- Exemplification: f = 1.0, c = w2c(f1*f2*c1*c2)
- Single-premise |- returns negation: f_neg = 1-f, c_neg = c

## NAL RULES (from lib_nal.metta lines 108-137)
- Revision: same term T with different TVs -> Truth_Revision
- Deduction: (--> a b) + (--> b c) -> (--> a c) via Truth_Deduction
- Induction: (--> a b) + (--> a c) -> (--> c b) via Truth_Induction
- Abduction: (--> a c) + (--> b c) -> (--> b a) via Truth_Abduction
- Exemplification: (--> a b) + (--> b c) -> (--> c a) via Truth_Exemplification
- Similarity structural: (<-> S P) -> (<-> P S)
- Resemblance: (<-> M P) + (<-> S M) -> (<-> S P)
- Comparison: (--> P M) + (--> S M) -> (<-> S P) [shared predicate]
- Comparison variant: (--> M P) + (--> M S) -> (<-> S P) [shared subject]
- Analogy: (<-> S P) + (--> P M) -> (--> S M) via Truth_Analogy

## NAL7 TEMPORAL REASONING (|-t operator, from lib_nal7.metta)
- Must import: !(import! &self lib_nal7) - file must be in ~/PeTTa/ (copied from repos/mettaclaw/)
- Temporal induction: (|-nal7 (eventA TV1) (eventB TV2)) -> ((=/> eventA eventB) Truth_Induction)
- Also produces (&/ eventA eventB) (Truth_Intersection)
- Temporal chaining: (=/> A B) + (=/> B C) -> (=/> A C) via Truth_Deduction (0.9^2=0.81 conf)
- Temporal modus ponens: eventA + (=/> eventA eventB) -> eventB via Truth_Deduction
- Temporal induction: (=/> A B) + (=/> A C) -> (=/> C B) via Truth_Induction
- Temporal abduction: (=/> A C) + (=/> B C) -> (=/> B A) via Truth_Abduction
- |-t is wrapper: (unique-atom (collapse (superpose ((|-nal7 $a $b) (|-nal7 $b $a)))))
- Link types: =/> (predictive implication), =|> (retroactive implication), </> (equivalence), <|> (concurrent equivalence)

## PLN (|~ operator)
- |~pln handles syllogistic rules with explicit link types (Inheritance, Implication, Similarity)
- STV function: (STV $X) returns (stv 0.1 0.9) by default - prior probability for induction
- SyllogisticRuleGuard: only Inheritance and Implication allowed for deduction/induction/abduction
- PLN format: (Inheritance A B) NOT (--> A B) - uses explicit link type atoms
- PLN modus ponens uses (Implication A B) format
- Deduction: same formula as NAL (f=f1*f2, c=f1*f2*c1*c2)
- Induction uses prior probabilities via STV function (key PLN advantage over NAL)
- Abduction also uses priors
- Modus Ponens: f = Ps*PQs + 0.02*(1-Ps), c = Ps*PQs*Pc*PQc
- Revision: same weighted average as NAL

## KEY DIFFERENCES: NAL vs PLN
- NAL |- is more expressive: produces abduction both directions + similarity, PLN only one direction
- PLN induction/abduction use prior probabilities (STV default 0.1), NAL does not
- NAL handles --> <-> ==> with shorthand, PLN needs Inheritance/Similarity/Implication explicit atoms
- NAL7 =/> temporal chaining requires lib_nal7 import (not auto-imported)
- NAL |- does NOT auto-chain transitive relations - need explicit MeTTa match rules
- Relational encoding: ((--> (x X Y) in) for "X is in Y") (Patrick 2026-08-11)
