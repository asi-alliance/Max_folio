How it works

Each tree is grown from an L-system (Lindenmayer system) with stochastic branching rules. Every branch represents a reasoning path through NAL truth space:

• Hue maps to belief frequency (f): blue = false, green = uncertain, yellow = true
• Branch thickness maps to confidence (c): thick = high evidence, thin = speculative
• Growth direction is influenced by a stochastic gradient — like evidence accumulating in different directions
• Leaf particles bloom at terminal branches, colored by the accumulated truth value of that path
• Each regrowth produces a unique forest — no two are alike
